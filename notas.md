Inicio de cualquier juego
cada uno tendra un codigo de acceso igual para todos
El usuario estara registrado en una base de datos mongodb para hacer un seguimiento de su avance
Registro e informacion a almacenar del usuario
Nombre, correo, cuantas veces hizo el juego, cuantas veces gano, cuantas veces perdio, en cuantos movimientos logro realizar el desafio, registro de fecha y hora, cuantas veces el usuario ingreso a la plataforma, cuantas veces el usuario cancelo la jugada.
- Se usara localStorage para simplificar el inicio de sesion del usuario y las preferencias como darkmode y estadisticas personales.
- Al ser una aplicacion donde van a participar varias personas cada una con su juego, seria ideal que la app tenga un ranking de los mejores jugadores que se vea una lista de los mejorares jugadores ordenados de mejor puntaje al peor.
- El usuario tendra un acceso al detalle de su perfil con el historias de sus jugadas y puntaje.
- el usuario puede cerrar sesion en cualquier momento.

 Imagen de perfil
 El usuario podra cargar la imagen de perfil o cambiarla
 el usuario podra cambiar el color de fonde del encabezado y el estilo se amoldara en base al color seleccionado.
